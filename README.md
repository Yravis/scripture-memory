# Scripture Memory

A phone-first web app for memorizing Bible verses (KJV) in a few minutes a day. It runs entirely in the browser: no backend, no accounts, no API keys. Your verses and progress are stored on your device, with JSON export/import for backup.

Live site (once deployed): https://yravis.github.io/scripture-memory/

## How it works

- **Add verses** by reference (`John 3:16`, `Proverbs 3:5-6`) or from the starter suggestions. Text is fetched once from [bible-api.com](https://bible-api.com) (KJV) and cached locally. If a fetch fails you can paste your own text, and you can edit text later.
- **Practice modes**, easiest to hardest: Read (tap words to hide), Hide words (25/50/75/100%), First letters, Fill in the blanks (3–5 words, more over time), Word order, Full recall (type it from the reference; case/punctuation ignored, small typos forgiven, 95% word accuracy to pass), plus a "name the reference" quiz.
- **Spaced repetition**: after a passed full recall, reviews come at 1, 3, 7, 14, 30, 60 and 120 days. A failed review drops back to the 1-day step and sends the verse back through first-letter practice.
- **Status**: *Learning*, *Memorized* (passed on 3 separate days including the 7-day review), *Needs review* (due, or last recall under 95%), *Mastered* (passed the 30-day review or later).
- **Points & streak**: harder modes earn more; on-time reviews and reaching Memorized/Mastered earn bonuses. Any day with a completed session keeps the streak.
- **Settings**: optional leniency for archaic forms (thee/thou/-eth), light/dark theme, backup.

Exact KJV wording is required by default. Extra practice from the Verses tab earns points once per mode per day and never changes the review schedule.

## Develop

```sh
npm install
npm run dev      # local dev server
npm test         # unit tests (scoring, recall accuracy, scheduling, status)
npm run build    # type-check + production build into dist/
npm run preview  # serve the production build (service worker active)
```

The site is built with base path `/scripture-memory/` (see `vite.config.ts`). If you rename the repo, change `BASE` there and the three absolute URLs in `index.html`. Icons are generated by `npm run icons`.

## Deploy to GitHub Pages

1. Push this repo to GitHub (`Yravis/scripture-memory`).
2. In the repo go to **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Push to `main` (or run the "Deploy to GitHub Pages" workflow from the Actions tab). The workflow runs tests, builds, and publishes `dist/`.
4. Open https://yravis.github.io/scripture-memory/.

## Add to your home screen

**iPhone (Safari):** open the site, tap the Share button, choose **Add to Home Screen**, then **Add**.

**Android (Chrome):** open the site, tap the ⋮ menu, choose **Install app** (or **Add to Home screen**).

Open it once online and let it load; after that it works offline (verses you've added are already saved on the device). Adding new verses needs a connection unless you paste the text yourself.

## Data & privacy

All data lives in your browser's `localStorage` on this device. Clearing site data erases it, and iOS may clear storage for sites unused for weeks when not installed, so use **Settings → Export backup** occasionally. Home-screen installs on iOS are more durable. The only network request is to bible-api.com when you add a verse (limit: 15 requests per 30 seconds; the "Add all suggestions" button paces itself).
